# Construct-3-Asset-Extractor
Couldn't find an extractor for the assets.dat file generated by the Construct 3 game engine from a game I downloaded. So I looked into the file with a hex editor, found some patterns, asked a few LLMs, tested their answer on my example and found it to be working.

**WARNING: THIS IS ENTIRELY AI GENERATED(GLM 5.3 Flash) CODE, AND ONLY TESTED ON A SINGLE, UNCOMPRESSED AND UNENCRYPTED PROJECT**

## How to use
Place unpack.py in the same directory as your assets.dat file. And run via a terminal like cmd: (Change output_directory to the folder where you want the extracted files to go)
```
python unpack.py assets.dat <output_directory>
```

## Notes
I've only tested it on a single game. The game does not appear to use any encryption and compression(not sure if this is a feature Construct 3 offers, if it does, this script will not work).
